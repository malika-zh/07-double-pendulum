# Chaotic Double Pendulum Simulation

An interactive browser-based simulation of a chaotic double pendulum built using HTML5 Canvas and JavaScript. This project visualizes complex non-linear dynamics, chaotic motion, and the "butterfly effect" using advanced mathematical modeling.

## 🚀 Features
- **Lagrangian Mechanics:** Computes physical accelerations via rigorous differential equations of motion derived from the Lagrangian of the system.
- **Chaotic Trajectory Trail:** Renders a fading tail effect that traces the unpredictable, non-repeating path of the lower bob.
- **Numerical Stability:** Implements multi-step numerical integration per frame to ensure smooth and physically accurate motion.
- **Air Resistance Damping:** Includes subtle energy dissipation to mimic real-world physics.

## 🛠️ Technologies Used
- **HTML5 Canvas** (for high-performance 2D vector graphics rendering)
- **Vanilla JavaScript (ES6+)** (for physics calculations and animation loops)
- **CSS3** (for modern, centered dark-themed UI layout)

## 📦 How to Run
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
